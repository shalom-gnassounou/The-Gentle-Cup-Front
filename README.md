🌿 TheGentleCup

A web application dedicated to non-alcoholic drink recipes.

🎯 Project goal

The goal of this project is to create a simple and accessible platform where users can discover and explore non-alcoholic drink recipes.

CSS3
JavaScript

Recipe listing
Recipe details view

Clean and simple UI focused on usability
