# The Gentle Cup – Frontend

Frontend application built with Angular for managing recipes, users, and data visualization within The Gentle Cup project.

## Overview
This Angular application provides a clean and responsive interface for interacting with the backend API.  
Users can authenticate, browse recipes, manage their data, and perform import/export operations.

The project was developed as part of my Web & Web Mobile Developer certification (2026).

## Features
- User authentication (JWT)
- Responsive UI built with Angular components
- Recipe management (CRUD)
- Dynamic forms and validation
- Integration with REST API (Node.js / Express backend)
- Import/export of structured data (JSON / CSV)
- Routing and protected routes
- Reusable services and modular architecture

## Tech Stack
- Angular 16+
- TypeScript
- HTML / SCSS
- RxJS
- Angular Router
- Angular Forms

## Installation
1. Clone the repository  
2. Install dependencies (npm install)
3.  Start the development server(ng serve)
4.  Access the app Open your browser at: http://localhost:4200


## API Integration
This frontend communicates with the backend API (Node.js / Express).  
Make sure the backend is running and update the API base URL in the environment files if needed: /src/environments/environment.ts
